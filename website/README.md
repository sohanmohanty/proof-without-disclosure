# Proof Without Disclosure: website

The interactive half of [Proof Without Disclosure](../README.md): six
cryptography modules with live demos, "try to cheat" modes, and a universal
drag-and-drop verifier for files generated by the `prooflab` CLI.

All cryptography runs client-side (Web Crypto + native BigInt). The build is
a fully static bundle: no server code, no uploads, no analytics.

## The 3D journey landing

The landing page is a scroll-driven 3D tour of the six modules (React Three
Fiber + three.js), and it follows the project's rule that visuals must be
*computed, not decorated*: the hero lattice shows real SHA-256 bits of
whatever you type, the Merkle chapter assembles the real tree of the sample
student list, the Schnorr chapter animates a real toy-group transcript, and
so on, all driven by the same `src/crypto/` modules the labs use.

Engineering notes:

- **Isolation.** The whole experience is one lazy-loaded chunk
  (`src/experience/`); visitors who get the classic page never download a
  byte of three.js.
- **Fallbacks.** No WebGL, `prefers-reduced-motion`, or an explicit
  `?classic=1` all fall back to the classic landing page (a visible
  "Classic page" control offers the same escape). A "Skip the tour"
  control is always available, plus per-chapter progress dots on
  viewports wider than 700px.
- **Native scroll.** Nothing hijacks the wheel: the canvas is sticky and
  caption sections scroll over it, so keyboard and screen readers see a
  normal document (all text is real HTML).
- **Loading screen.** The intro overlay "computes" `sha256("proof-without-
  disclosure")` (really) while the chunk warms up. Once per session,
  skippable with any input.
- **Theming.** Scenes read the site's CSS custom properties, so the 3D
  world follows light/dark mode live.
- **Budgets.** Instanced meshes throughout, capped device-pixel-ratio,
  reduced particle counts on mobile, render loop fully stopped once you
  scroll past the journey, and only the active chapter ± 1 is mounted.

## Develop

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # vitest suites, including shared-vector interop
npm run build      # type-check + static bundle in dist/
npm run preview    # serve the production bundle locally
```

## Deploy

`vite.config.ts` uses `base: "./"` and the app uses hash routing, so
`dist/` works from **any** static host or subdirectory with zero
configuration: GitHub Pages, Netlify, Vercel, or a plain file server.
Build and upload `dist/`.

## Structure

```
src/
|-- crypto/       # TypeScript implementations (mirror prooflab/, see
|                 # ../docs/format-spec.md): hash, commitments, merkle,
|                 # schnorr, signatures, graphColoring, format (verifier)
|-- experience/   # 3D journey landing (lazy chunk): timeline, journey
|   |             # state, palette/theming, intro overlay, captions
|   `-- chapters/ # one R3F scene per chapter (hero bit-field + 6 modules
|                 # + outro), all driven by src/crypto/ output
|-- components/   # Layout, LabPage, Dropzone, MerkleTreeSVG, GraphSVG, ...
|-- routes/       # Landing (3D/classic switch), Home + 6 labs + Toolkit + About
`-- tests/        # vitest suites incl. vectors.test.ts (interop pin) and
                  # experience.test.ts (timeline/bit-field math)
```
